    HiReS documentation¶

    Version 2.0 · Source · Issues · Release notes

    HiReS (High-Resolution Segmentation) is a Python library and command-line tool for instance segmentation and morphometric analysis of images that are too large for a single neural-network pass. It cuts a scan into overlapping tiles, runs a YOLO segmentation model on each tile, stitches the detections back into polygons in full-image coordinates, measures the shape of every object, and evaluates the result against ground truth.

    import hires

collection = hires.segment("scan.tif", "DaphnAI.pt")
collection.with_scale(dpi=2400, unit="um").to_csv("traits.csv")

    What HiReS does¶

    Tiled segmentation
    Images of 10,000 × 10,000 pixels and more are split into overlapping tiles so that inference runs on a laptop CPU or a single GPU. Objects cut by a tile border are dropped from that tile and recovered from its neighbour; duplicates are removed with polygon non-maximum suppression. See Tiled segmentation.
    A small, immutable data model
    Annotation (one polygon), Collection (one image) and Album (one dataset). Every operation returns a new object, so pipelines are chains of method calls with no hidden state. See The data model.
    Morphometric traits
    Area, perimeter, solidity, convexity, circularity and the dimensions of the axis-aligned and oriented bounding boxes, in pixels or in physical units derived from the scan resolution. See Morphometric traits.
    Evaluation against ground truth
    IoU matching, per-class precision, recall, F1 and average precision, confusion matrices, precision-recall curves and per-object comparison figures. See Evaluation.
    Model-agnostic
    Any Ultralytics YOLO segmentation model works, as does any object with a compatible predict() method. YOLO itself is an optional dependency: reading, measuring and evaluating label files needs no deep-learning stack.

    How the package is organised¶

    HiReS is laid out like NumPy or SciPy. The objects you use every day live in the top-level namespace; specialised functionality lives in submodules.

    Namespace Contents
    hires Data model, readers, segment, run_pipeline, measure, evaluate
    hires.metrics Matching predictions to ground truth and detection metrics
    hires.plot Overlays, comparison images and evaluation charts
    hires.tiling Splitting images and labels into tiles and merging them back
    hires.io Low-level image and label reading helpers
    hires.analysis Trait-agreement plots (legacy)
