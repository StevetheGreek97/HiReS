# Measurement

Morphometric traits of polygons. In everyday use, traits are obtained from
[`Collection.to_frame`][hires.Collection.to_frame] or
[`Annotation.traits`][hires.Annotation.traits]; `hires.measure` is the
function underneath. See
[Morphometric traits](../user-guide/morphometrics.md) for the definitions.
