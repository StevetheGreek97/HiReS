# Segmentation

Tiled inference with a YOLO segmentation model. See
[Tiled segmentation](../user-guide/segmentation.md) for the algorithm and
for advice on choosing the parameters.

| Object | Use it to |
|--------|-----------|
| [`hires.segment`][hires.segment] | Segment one image in one call |
| [`hires.Segmenter`][hires.Segmenter] | Segment many images with one loaded model |
| [`hires.run_pipeline`][hires.run_pipeline] | Segment files and write labels, tables and overlays |
