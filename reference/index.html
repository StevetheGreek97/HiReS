    API reference¶

    The reference describes every public class, function and constant of HiReS. It assumes you know the concepts; for background and worked explanations, read the user guide.

    Everything listed here is public and covered by the compatibility policy. Names that start with an underscore, and anything not listed, are private and may change without notice.

    Top-level namespace¶

    import hires
    Object Description
    hires.Annotation One polygon with a class and an optional confidence
    hires.Collection The annotations of one image
    hires.Album The collections of one dataset
    hires.read_txt, hires.read_album, hires.read_class_names Readers for label files and class names
    hires.segment, hires.Segmenter, hires.run_pipeline Tiled segmentation
    hires.measure, hires.TRAIT_NAMES, hires.UNITS Morphometric traits
    hires.ClassMapping, hires.build_class_mapping Translating class ids between schemas
    hires.evaluate Full evaluation report on disk
    hires.HiresError and subclasses, hires.HiresWarning Exceptions and warnings
    hires.show_versions Version report for bug reports
    hires.__version__ The installed version, as a string

    Submodules¶

    Submodules are available as attributes after import hires.

    Module Description
    hires.metrics Matching predictions to ground truth and detection metrics
    hires.plot Overlays, comparison images and evaluation charts
    hires.tiling Splitting images and labels into tiles and merging them back
    hires.io Low-level image and label reading helpers
    hires.analysis Trait-agreement plots (legacy)

    def show_versions() -> None:
    """Print the versions of HiReS and its dependencies.

    Include the output when reporting a bug.

    Examples
    --------
    >>> hires.show_versions()  # doctest: +SKIP
    hireseg      : 2.0.0
    python       : 3.12.3
    ...
    """
    import platform

    rows = [
        ("hireseg", __version__),
        ("python", platform.python_version()),
        ("platform", platform.platform()),
    ]
    for module in (
        "numpy", "pandas", "shapely", "PIL", "cv2", "matplotlib", "yaml", "ultralytics", "torch",
    ):  # fmt: skip
        try:
            found = getattr(importlib.import_module(module), "__version__", "unknown")
        except ImportError:
            found = "not installed"
        rows.append((module, found))
    for name, value in rows:
        print(f"{name:<12} : {value}")
